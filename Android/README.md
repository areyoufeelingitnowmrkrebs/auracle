# Android
The Android version of Auaracle is a native live wallpaper service written in Kotlin.

## Install
1. Tap [here](https://github.com/areyoufeelingitnowmrkrebs/auracle/archive/refs/heads/main.zip) to download a zip of this repo.

2. Open your phone's Files app, then go to `Internal storage/Download` and tap on the downloaded zip to extract it.

<img width="50.2%" alt="Step2-1" src="https://github.com/user-attachments/assets/f3b013ba-c302-4e64-88dd-29c4e5a9719c" /><img width="47.8%" alt="Step2-2" src="https://github.com/user-attachments/assets/fbe8a38d-2f11-45d6-af16-e81769bf142e" />

3. Go to `auracle-main/auracle-main/Android` and tap on `Auracle.apk`.

*You may be prompted to enable install permissions, and/or warned by Play Protect; this is all perfectly normal.*

<img width="49%" alt="Step3-1" src="https://github.com/user-attachments/assets/071417b7-bf53-479b-be6e-ee6b4c922303" /><img width="49%" alt="Step3-2" src="https://github.com/user-attachments/assets/e9e913f3-4708-4868-ab8b-bea95450233a" />

4. Hold down on any empty space in your home screen.

5. Go to `Wallpaper & style > More wallpapers`.

<img width="49%" alt="Step5-1" src="https://github.com/user-attachments/assets/38631450-0a62-4bd6-b872-22fdaaddad48" /><img width="49%" alt="Step5-2" src="https://github.com/user-attachments/assets/fcdd3cfe-0bcf-4706-8f21-78c6cf4ae6dd" />

6. Scroll to the bottom, where you should now see a `Live wallpapers` folder if there wasn't one before. Auracle is in there.
