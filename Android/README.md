# Android
The Android version of Auaracle is a native live wallpaper service written in Kotlin.

## Install
1. Click [here](https://github.com/areyoufeelingitnowmrkrebs/auracle/archive/refs/heads/main.zip) to download a zip of this repo.
2. Extract the downloaded zip.
3. Go to `auracle-main/Android` and tap on `Auracle.apk`.
    * *You may be prompted to enable install permissions, and/or alerted about Android or Play Services not being able to scan the app; this is all perfectly normal.*
4. Hold down on any empty space in your home screen.
5. Go to `Wallpaper & style > More wallpapers`.
6. Scroll to the bottom, where you should now see a `Live wallpapers` folder if there wasn't one before. Auracle is in there.
